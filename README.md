# Amlak Sadr - Garmdarreh Real Estate Platform (پلتفرم املاک صدر گرمدره)

پلتفرم مدرن جستجو، خرید، فروش، رهن و اجاره آپارتمان، باغ‌ویلا و زمین در منطقه گرمدره البرز (گرمدره شمالی، جنوبی، بلوار امیرکبیر، کوهک و شهرک شاهد).

## ویژگی‌ها (Features)
- 🏢 **رابط کاربری مدرن و واکنش‌گرا**: پیاده‌سازی شده با Next.js 16 (App Router)، React 19، Tailwind CSS و انیمیشن‌های نرم Framer Motion.
- 🔍 **سیستم فیلتر و جستجوی پیشرفته ملک**: فیلتر بر اساس منطقه (گرمدره شمالی، گرمدره جنوبی، بلوار امیرکبیر، کوهک)، متراژ، قیمت و نوع معامله.
- 🗺️ **موقعیت‌یابی و نقشه تعاملی**: نمایش موقعیت محله‌ها با نقشه Leaflet و اطلاعات منطقه‌ای.
- 📱 **سازگاری کامل با موبایل و تبلت**: بهینه‌سازی دقیق تمامی المان‌ها و فرم‌های ارتباطی برای دیوایس‌های مختلف.
- ⚡ **حالت Standalone / دمو آنلاین**: دارای دیتای نمونه کامل جهت استقرار و اجرا روی GitHub Pages بدون نیاز اجباری به بک‌اند.

## شروع به کار محلی (Local Development)

```bash
# نصب پکیج‌ها
npm install

# اجرای سرور توسعه
npm run dev
```

آدرس محلی: `http://localhost:3000`
